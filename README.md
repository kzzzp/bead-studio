# 豆格 · 拼豆图纸生成器

完全在浏览器本地运行的照片转拼豆图纸工具，覆盖构图、转换、精修、打印、保存工程和按图拼豆的完整流程。

主要能力：

- 本地 AI 主体抠图、人工修边、裁剪、缩放、旋转、翻转和主体居中。
- 卡通、真人、宠物、像素原图和线稿转换模式。
- 画笔、橡皮、填充、吸管、框选、批量换色及 50 步撤销/重做。
- MARD、Perler、Hama 和自定义色卡，支持库存色停用与近似色查询。
- 高清 PNG 和镜像成品图；当前样式 PNG、SVG 与 CSV 收纳在更多导出格式中。
- A4/A3/自定义纸张的真实尺寸 PDF，支持自动方向、分页重叠、定位标记与 50 mm 校准尺。
- IndexedDB 自动保存、历史快照、工程导入导出和本地拼豆进度辅助。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 设计说明

- 上传的图片只在浏览器内解码和处理，不会发送到服务器。
- 色彩匹配使用 CIELAB 欧氏距离，而不是直接比较 RGB。
- 限色采用基于像素权重的贪心调色板选择，再将每个像素映射到所选 MARD 色号。
- 显示色值来自公开色卡资料，是屏幕近似值；不同批次、光照和显示器会造成实物色差。
