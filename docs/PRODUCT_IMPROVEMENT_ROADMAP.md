# 豆格 · 产品改进路线图

> 状态：已完成首轮实现与验收
>
> 最近更新：2026-07-29
>
> 适用范围：图片导入、主体处理、拼豆图纸生成、编辑、导出和拼豆执行辅助

## 1. 文档目的

豆格目前已经具备图片本地处理、MARD 色卡匹配、限色、抖动、主体抠图、手动修边、高清 PNG、SVG、真实尺寸 PDF 和 CSV 导出等基础能力。

下一阶段的目标不是继续堆叠简单的“图片转像素”选项，而是补齐从图片构图、生成、精修、打印到实际拼豆的完整工作流，让用户能够：

1. 准确控制图片中的主体、比例和位置。
2. 在生成后修正不满意的格子和色号。
3. 使用不同品牌或自定义色卡。
4. 直接获得可镜像、可打印、可实际使用的图纸。
5. 保存工程，并在后续继续编辑或按图完成拼豆。

## 2. 产品边界

### 本路线图包含

- 图片裁剪、缩放、旋转、翻转和主体居中。
- 拼豆图纸的像素级编辑和批量改色。
- 多品牌色卡、自定义色卡和缺色替换。
- 普通图纸、镜像图纸和真实尺寸打印文件。
- 多种图片转换模式与图纸展示样式。
- 本地工程保存、恢复和导入导出。
- 本地拼豆进度与执行辅助。

### 明确不做

以下内容不属于当前产品方向，不进入后续开发计划：

- 公共图纸库。
- 收藏功能。
- 分享链接或分享口令。
- 作者主页。
- 热门模板和内容推荐。
- 社区、关注、评论、排行榜等内容生态功能。

分享海报只作为本地导出样式，不包含发布平台、作者系统或社区能力。

## 4. P0：必须优先完成

### P0-01 像素图纸编辑器

#### 目标

让用户能够修复自动转换产生的杂色、断线、错误轮廓和不合理色号，而不必重新处理原图。

#### 功能范围

- 单格画笔：使用选中的色号修改格子。
- 橡皮：将格子设为空白，空白格不计入豆子数量。
- 填充：替换一个连续区域的颜色。
- 吸管：从图纸中选择已有色号。
- 框选：选择矩形区域并进行清空、填充、移动或复制。
- 全局替换：将某个色号一次性替换为另一个色号。
- 撤销和重做：覆盖画笔、填充、删除、框选和批量替换操作。
- 编辑后实时更新颜色用量、豆子总数、成品尺寸和导出内容。
- 支持在编辑前后切换对比，不影响原始上传图片。

#### 验收标准

- 修改任意格子后，预览、统计、PNG、SVG、PDF 和 CSV 结果一致。
- 删除格子后，该格不显示色号，也不进入颜色数量统计。
- 全局替换不会改变空白格或其他未选择色号。
- 至少支持 50 步撤销和重做。
- 100×100 图纸编辑时保持可用，不出现明显卡顿或误触。

### P0-02 多品牌与自定义色卡

#### 目标

减少用户手工查询替换色号的成本，使生成结果与用户实际拥有的拼豆品牌一致。

#### 功能范围

- 色卡品牌选择器。
- 首批建议支持 MARD、COCO、漫漫、盼盼、Perler 和 Hama。
- 每个品牌独立维护色号、显示色值、名称和可选状态。
- 支持用户禁用缺货色号，再重新匹配图纸。
- 支持跨品牌近似色查询和替代建议。
- 支持导入、导出自定义色卡文件。
- 工程文件记录所用品牌和色卡版本，避免重新打开后色号变化。

#### 验收标准

- 切换品牌后，整张图纸重新匹配，统计和图例同步更新。
- 禁用某个色号后，生成结果中不再出现该色号。
- 自定义色卡导入失败时给出具体错误，不覆盖当前色卡。
- 导出的图纸必须清晰标明品牌名称，避免不同品牌同名色号混用。

#### 注意事项

- 屏幕色值只能作为近似值，文案中应提示批次、光线和显示器可能造成色差。
- 在正式内置第三方品牌色卡前，需要确认数据来源和使用许可。

### P0-03 镜像图纸

#### 目标

满足熨烫、反面展示和垫板拼豆等场景，避免用户依赖外部软件翻图。

#### 功能范围

- 普通/镜像预览切换。
- 单独导出普通图纸或镜像图纸。
- 镜像时仅翻转图案格子。
- 坐标数字、格内色号和图例文字重新绘制，保持正常阅读方向。
- 镜像前后颜色数量和豆子总数保持一致。

#### 验收标准

- 左右非对称测试图镜像后位置正确。
- 色号文本不会变成反字。
- 顶部、底部和两侧坐标仍从正常方向递增。
- 镜像图的空白格、图例和统计与普通图一致。

### P0-04 真实尺寸 PDF 与分页打印

#### 目标

让用户无需在 Word 或 WPS 中手动计算尺寸，即可按 100% 比例打印并与实际钉板对齐。

#### 功能范围

- 纸张：A4、A3 和自定义纸张。
- 方向：自动、横向、纵向。
- 打印比例：100% 原尺寸和适合纸张。
- 豆子/钉板规格：选择预设或输入实际格距毫米数。
- 显示最终图纸的物理宽度和高度。
- 大图自动分页，支持页面重叠区、裁切线、页码和拼接定位标记。
- 每份打印文件包含毫米校准尺或校准方块。
- 可分别导出普通版或镜像版。
- 在导出提示中明确说明打印时关闭“适应页面”缩放。

#### 验收标准

- 使用校准尺测量时，误差控制在普通打印机可接受范围内。
- 多页图纸拼接后不丢格、不重复格，跨页坐标连续。
- 29、40、52、58、104 格测试图均可正确分页。
- PDF 中的格子、色号、坐标和图例在实际打印后仍清晰可读。

### P0-05 可视化构图与比例控制

#### 目标

在像素化前确定最终构图，解决主体太小、人物偏移、重要部分被裁掉或背景占比过大的问题。

#### 功能范围

- 在上传后进入可视化裁剪界面。
- 支持拖动图片、缩放、旋转 90°、水平翻转和重置。
- 支持完整放入、铺满裁切和自由裁切。
- 比例预设：1:1、3:4、4:3、9:16 和自由比例。
- 格数预设：29×29、40×40、52×52、58×58、104×104。
- 支持自定义宽高，并可锁定或解除宽高比例。
- 抠图完成后可自动裁到主体边界，并设置主体周围留白格数。
- 支持一键主体居中，也允许用户继续手动调整。

#### 验收标准

- 裁剪预览与最终生成范围一致。
- 旋转、翻转和抠图可以组合使用，不丢失透明区域。
- 切换格数时主体中心和用户选择的构图尽量保持不变。
- 自动居中不会把头发、帽子、手持物或宠物边缘裁掉。

## 5. P1：完善生成和复用能力

### P1-01 图片类型转换模式

#### 计划模式

| 模式 | 主要处理方向 |
| --- | --- |
| 卡通 | 保留清晰色块和轮廓，减少渐变和杂色 |
| 真人照片 | 优先保留五官、肤色层次和主体明暗关系 |
| 宠物 | 保留眼睛、鼻子、耳朵轮廓和毛色主区域 |
| 像素原图 | 关闭不必要的平滑和抖动，尽量保持原始像素边界 |
| 线稿 | 强化边缘，减少背景色并控制线条连续性 |

#### 通用要求

- 模式只是可调整的预设，用户仍可修改颜色数、饱和度、亮度、对比度和抖动。
- 显示模式说明和适用图片示例。
- 支持原图与结果的快速对比。
- 切换模式时避免重复执行抠图模型。

#### 验收标准

- 同一张测试图切换模式时能够产生可解释的差异。
- 卡通模式的杂色数量应明显低于通用模式。
- 像素原图模式不会无故增加颜色或模糊硬边缘。

### P1-02 图纸展示与导出样式

#### 计划样式

- 色号图：彩色格子叠加色号，适合按图拼豆。
- 纯色块图：不显示色号，适合观察整体效果。
- 圆珠效果图：使用圆形或带高光的豆子预览成品观感。
- 镜像图：用于反向拼豆或熨烫场景。
- 1:1 垫板图：按真实格距打印，放在透明钉板下使用。
- 分享海报：包含图案、尺寸、用色数和用量，仅作为图片导出。

#### 可配置项

- 坐标显示位置和字号。
- 格内色号字号、字重和自动对比色。
- 普通网格线和板块分隔线的颜色、粗细和间隔。
- 图例位置、字号、卡片大小和每行数量。
- 空白区域显示为白色、透明或指定画板色。

#### 验收标准

- 大尺寸图纸自动放大色号，或通过分页保证可读性。
- 每种样式的 PNG、SVG 和 PDF 结果与预览一致。
- 分享海报不引入账号、作者主页、社区或分享口令功能。

### P1-03 本地工程保存

#### 目标

避免刷新、关闭页面或更换设备前丢失构图、抠图和手动修改结果。

#### 功能范围

- 自动保存当前工程到浏览器本地。
- 显示最近编辑时间和恢复提示。
- 手动保存为新方案或复制方案。
- 导出工程文件，并可再次导入。
- 工程包含原图引用或内嵌图片、裁剪参数、抠图蒙版、色卡版本、转换参数、图纸数据和编辑历史。
- 提供清除本地工程的入口，并明确说明数据只保存在本机。

#### 验收标准

- 刷新页面后可恢复到最近一次稳定状态。
- 导入工程后，图纸、统计、色卡和导出结果一致。
- 旧版本工程无法完全兼容时，给出迁移提示而不是直接报废。
- 损坏的工程文件不会覆盖当前正常工程。

## 6. P2：拼豆执行辅助

### P2-01 本地拼豆进度模式

#### 功能范围

- 选择一个色号后，高亮所有对应格子。
- 点击格子标记完成或未完成。
- 支持按色号、行列或板块逐步完成。
- 隐藏或降低已完成格子的透明度。
- 显示整体、各色号和各板块完成进度。
- 进度保存在本地工程中。
- 提供防误触和批量取消完成标记。

#### 验收标准

- 进度标记不会修改原始图纸颜色或豆子数量。
- 切换普通图和镜像图时，完成位置能够正确映射。
- 刷新或重新打开工程后，完成进度可以恢复。
- 不要求登录，不依赖服务器或公共内容平台。

## 8. 全局质量要求

所有新功能都需要满足以下要求：

- 图片、蒙版、图纸和工程默认只在浏览器本地处理。
- 空白格不显示色号，也不计入豆子数量和颜色用量。
- 预览、统计和各导出格式使用同一份图纸数据，避免结果不一致。
- 40×40、58×58、100×100 和 120×120 图纸均需纳入性能测试。
- 生成和导出过程中需要显示进度，并允许用户理解失败原因。
- 移动端和 iPad 浏览器必须能够稳定保存导出文件。
- 所有关键操作支持键盘或明确的触控替代方案。
- 不因新增功能破坏当前高清 PNG、SVG、真实尺寸 PDF、CSV、抠图和手动修边能力。

- [ ] README 或相关文档已同步更新。
- [ ] 不包含本路线图明确排除的内容生态功能。
